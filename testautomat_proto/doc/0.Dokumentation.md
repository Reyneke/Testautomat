## Zusammenfassung

Der **Testautomat** ist ein Prototyp für das Bedienterminal eines Parkautomaten in der Stadt Weiden.
Er bildet den kompletten Kaufablauf am Automaten ab:

1. Der Kunde startet den Verkauf.
2. Der Kunde wählt Parkdauer (und Parkzone).
3. Der Kunde wählt eine Zahlungsart.
4. Der Kunde erhält die Parkinformationen.
5. Der Kunde wird verabschiedet.

Wichtige Punkte:

- **Alle Zahlungen sind nur simuliert** — es fließt kein echtes Geld.
- **Auch der Parkschein ist nur simuliert**.
- Die App läuft auf **Android, Windows, Linux und im Browser**.
- Die Bedienung ist auf **Deutsch und Englisch** möglich.
- Die Oberfläche kann **hell oder dunkel** dargestellt werden.

## Ausprobieren

Die Web-Version läuft direkt im Browser — ganz ohne Installation:

- **Im Browser öffnen:** <https://reyneke.github.io/Testautomat/>

Fertige Programme zum Installieren gibt es auf GitHub:

- **Android (APK), Windows und Linux:** [Releases](https://github.com/Reyneke/Testautomat/releases/latest)

Wichtige Hinweise:

- Alle **Zahlungen und Parkscheine sind nur simuliert**.
- Die Programme sind **un-signiert**. Das Betriebssystem zeigt beim Installieren deshalb eine Warnung.

## Selbst bauen (Quickstart)

**Voraussetzung:** Flutter SDK (Stable-Channel, Version laut `pubspec.yaml`).

```bash
flutter pub get     # Abhängigkeiten laden
flutter run         # App starten (Ziel wählen: Windows, Android oder Browser)
flutter test        # Tests ausführen
flutter analyze     # Code auf Fehler prüfen
```
